# MLIFT
A dual-branch multi-scale feature extraction mechanism is proposed to achieve the coordinated perception of local mutations and global trend features in multi-source signals of hydraulic pumps.

A multi-scale linear interaction mechanism is designed to generate multi-scale tokens representations through lightweight small-kernel convolution, and expand the receptive field by combining cross-dimensional linear interaction structure.

A fusion strategy based on the Pearson correlation coefficient is constructed to model the key-value matrix and explore the intrinsic connection between different modalities from the perspective of statistical correlation.
